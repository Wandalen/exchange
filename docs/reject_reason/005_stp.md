# Reject Reason: Stp

### Scope

- **Purpose**: Name a self-trade-policy outcome as a reject rather than silently reclassifying it as a cancel.
- **Responsibility**: One of the nine reject-reason values.
- **In Scope**: Communicating to the caller that a self-trade policy fired.
- **Out of Scope**: Which of the three `stp_policy` values actually applied — that is carried elsewhere (`CancelCause::SelfMatch`), not re-derived from this reason alone.

**Design status**: Not implemented as named — the real `RejectReason` enum (`exchange_fill/src/lib.rs:108`, extracted out of `exchange_types` this session — `exchange_types` now only re-exports it) has a completely different variant set: `ZeroQuantity`, `NegativePrice`, `UnknownAccount`, `InsufficientFunds`, `ObligationUnrepresentable`, `ReservationUnrepresentable`. The real build does carry a comparable signal via `exchange_fill::CancelCause::SelfMatch`, just not as a `RejectReason` variant of this name.

### Statement

`Stp` would mark an order's outcome as shaped by the self-trade policy rather than by ordinary book conditions — relevant mainly under `CancelNewest`, where the incoming order itself is the one withdrawn. The real build already has an analogous signal (`CancelCause::SelfMatch`), so this is a naming/location gap rather than a missing capability.
