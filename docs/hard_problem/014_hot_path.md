# Hard Problem: Hot Path

### Scope

- **Purpose**: Many instruments per aeon stay cheap.
- **Responsibility**: Keep per-instrument, per-aeon matching cheap enough that many instruments stay affordable.

### Statement

Many instruments run every aeon, so the hot path — a book on every station — has to stay cheap, or the market itself becomes the bottleneck.
