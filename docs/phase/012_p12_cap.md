# Phase: P12 — Rest capacity

### Scope

- **Purpose**: Prove a full book rejects loudly instead of growing unbounded or dropping silently.
- **Responsibility**: A third rest beyond a cap of 2 returns `RestsFull`.

### Statement

The twelfth phase's one new contract: with a rest cap of 2, a third rest is refused with an explicit `RestsFull` error rather than accepted or silently dropped.
