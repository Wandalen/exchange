# Phase: P27 — Snapshot isolation from live cancel

### Scope

- **Purpose**: Prove a snapshot is a true copy, not a live view.
- **Responsibility**: Cancelling a live order after a snapshot was taken does not change that snapshot.

### Statement

The twenty-seventh phase's one new contract: a snapshot of resting rows is unaffected by a cancel that happens afterward on the live book — the snapshot still shows the row that was cancelled.
