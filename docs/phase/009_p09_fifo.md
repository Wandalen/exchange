# Phase: P09 — Level FIFO

### Scope

- **Purpose**: Prove one price level pops orders in arrival order.
- **Responsibility**: Two rests at the same price pop earliest-first.

### Statement

The ninth phase's one new contract: a single price level holding two rests at the same price pops the earlier one first — FIFO within a level, not insertion-order-agnostic.
