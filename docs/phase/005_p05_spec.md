### Scope

- **Purpose**: Prove an instrument spec rejects a degenerate tick.
- **Responsibility**: `InstrumentSpec` carries tick 0.05 and lot 1; a zero tick is an error, not a silently-accepted default.

### Statement

The fifth phase's one new contract: an instrument spec with a non-zero tick (0.05) and lot (1) constructs successfully, while a zero tick is rejected as an error.
