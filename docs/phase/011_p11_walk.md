# Phase: P11 — Sorted price walk

### Scope

- **Purpose**: Prove price traversal follows sorted order, not hash/map iteration order.
- **Responsibility**: Walking the book visits best price first, then the next-best, by sort order.

### Statement

The eleventh phase's one new contract: walking prices starts from the best and proceeds in sorted order (e.g. 1.00 then 0.95), never in whatever order a hash map happens to iterate.
