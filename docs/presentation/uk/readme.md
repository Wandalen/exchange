# uk

The Ukrainian deck for the bootcamp defence: a 3-minute talk over eight
slides, with the order book driven live by `exchange_core` compiled to
WebAssembly.

Open [`index.html`](index.html) from disk. `→` steps the demo, `Shift+→`
skips a slide, `n` shows the notes, `s` the full speech, `t` the timer.
Fonts come from Google Fonts when online; offline, system fonts stand in.

## Engine

[`engine/`](engine/src/lib.rs) puts `exchange_core` behind a one-line text
protocol (`reset`, `place`, `cancel`, `halt`, `resume`, `hash`) that answers
JSON, and builds to `wasm32-unknown-unknown` with no imports. The deck embeds
the module as base64 and runs it in the page. It is its own workspace root,
so CI and `verb/test` never build it.

Where WebAssembly is blocked, as in some sandboxed viewers, the deck falls
back to [`src/mirror.js`](src/mirror.js), a JS port of the same rules; the
badge in the nav bar says which one runs. [`mirror_test.cjs`](mirror_test.cjs)
holds the port to the wasm build: random sessions through both, failing on the
first answer that differs. Last run: 5 000 sessions, 176 962 commands, none
different.

## Build

```bash
rustup target add wasm32-unknown-unknown
python3 docs/presentation/uk/build.py
node docs/presentation/uk/mirror_test.cjs 5000
```

`index.html` is generated; edit `src/` or `engine/` and rebuild.

## Responsibility Table

| File | Responsibility |
|------|-----------------|
| [`index.html`](index.html) | The deck — generated by `build.py`, engine and scripts inlined |
| [`build.py`](build.py) | Builds `engine/` to wasm and inlines it with `src/` into `src/deck.html` |
| [`src/deck.html`](src/deck.html) | Slides and styles, with the slots `build.py` fills |
| [`src/app.js`](src/app.js) | The ladder, demo scenes, sandbox, navigation and speaker notes |
| [`src/scenarios.js`](src/scenarios.js) | The five demo scenarios — each step an engine command and its line |
| [`src/mirror.js`](src/mirror.js) | JS port of the engine's rules, used only when WebAssembly is unavailable |
| [`engine/`](engine/Cargo.toml) | `exchange_core` behind the text protocol, built to wasm32 |
| [`mirror_test.cjs`](mirror_test.cjs) | Random sessions through the wasm build and `src/mirror.js`; they must agree byte for byte |
