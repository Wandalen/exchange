# presentation

The 8-minute bootcamp presentation of this family, for two speakers and an
audience new to exchanges. One story, told in the order real-world problem →
why this solution → why not an existing crate → proof → what is missing.

## Responsibility Table

| File | Responsibility |
|------|-----------------|
| [`script.md`](script.md) | The timed talk track — who says what, what is on screen, and what to cut when over time |
| [`index.html`](index.html) | The deck — open from disk, no network; → next, ← back, `n` notes, `t` timer |
| [`trace.js`](trace.js) | The demo's recording of the real engine, generated by `exchange_core`'s `presentation_trace` example |
| [`uk/`](uk/readme.md) | The 3-minute Ukrainian deck, its demo and sandbox run by `exchange_core` built to wasm |
