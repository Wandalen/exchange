# Tif: Gtc

### Scope

- **Purpose**: Let an order rest on the book indefinitely until filled or cancelled.
- **Responsibility**: One of the three time-in-force values the source design names.
- **In Scope**: The default disposition for a resting limit order.
- **Out of Scope**: Partial-fill behavior itself (that is `exchange_match`'s job, not the TIF tag's).

**Design status**: Built as named — `exchange_tif::Tif::Gtc` (`src/lib.rs`).
`tif_rests( Tif::Gtc )` is `true`, so `exchange_core` rests the remainder.

### Statement

"Good Till Cancel" is the order that rests: whatever quantity does not fill immediately stays on the book at its level until the owner cancels it or it fills later.
