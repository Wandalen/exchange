# Tif: Gtc

### Scope

- **Purpose**: Let an order rest on the book indefinitely until filled or cancelled.
- **Responsibility**: One of the three time-in-force values the source design names.
- **In Scope**: The default disposition for a resting limit order.
- **Out of Scope**: Partial-fill behavior itself (that is `exchange_match`'s job, not the TIF tag's).

**Design status**: Built exactly as named — `exchange_tif::Tif::Gtc`
(`src/lib.rs`). `tif_rests( Tif::Gtc )` is `true`; this remains every order's
disposition by default, since `exchange_core::Exchange::submit` still
hardcodes `Tif::Gtc` regardless of what a caller might eventually supply —
see this crate's own [`../../readme.md`](../../readme.md), "Genuinely new".

(Superseded note: this file previously said "Not implemented ... no `Tif`
type exists anywhere" — false now; the type and all three variants are
real and tested.)

### Statement

"Good Till Cancel" is the order that rests: whatever quantity does not fill immediately stays on the book at its level until the owner cancels it or it fills later. It is the implicit, and currently only, behavior of the real book — every order behaves as GTC today because `exchange_core` has not yet wired up a caller-supplied choice, not because the other values don't exist.
